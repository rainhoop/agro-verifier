# Деплой на Render

Проект содержит `Dockerfile` и может быть развёрнут на Render как Docker Web
Service на тарифе Free. Создайте Web Service из этого GitHub-репозитория,
выберите Dockerfile и укажите переменные окружения в панели Render.

Для Groq задайте `LLM_API_KEY` как секрет Render. При отсутствии явных
`LLM_BASE_URL` и `LLM_MODEL` приложение использует endpoint Groq и модель
`llama-3.1-8b-instant`. Не добавляйте ключ в репозиторий или URL.

Для спутниковых данных задайте `CDSE_CLIENT_ID` и `CDSE_CLIENT_SECRET`.
Без учётных данных сервис работает с предзагруженными примерами и использует
обозначенный синтетический fallback для пользовательских контуров при
недоступности CDSE. Render передаёт переменную `PORT`; Dockerfile использует её
для запуска приложения.

Подробности переменных и локального запуска приведены в [README.md](README.md).
