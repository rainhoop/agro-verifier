## Качество ответов LLM (ноябрь 2026)

### Сделано

- Перед показом объяснение и ответ чата проверяются: пустой основной текст, неразрешённая латиница (включая слова со смешением алфавитов), markdown-таблицы, LaTeX и превышение лимита длины отклоняются.
- При отклонении качества запрос повторяется один раз; повторно отклонённое объяснение или чат заменяется шаблоном с `source: template`. Ошибки провайдера сохраняют прежний fallback.
- Казахский интерфейс использует `LLM_MODEL_KK`, если переменная задана; иначе берётся `LLM_MODEL`. Выбор модели учитывается и при проверке доступности локального LM Studio, и при запросах из интерфейса.
- Системные промпты требуют язык интерфейса, короткие простые предложения, отсутствие markdown и латиницы кроме разрешённого списка терминов, а также опору только на переданные числа.
- Лимиты запроса: `max_tokens=1000` для объяснения, `800` для чата; таймаут остаётся 8 секунд.
- `LLM_MODEL_KK` описана в `.env.example` и README. Новых зависимостей нет.
