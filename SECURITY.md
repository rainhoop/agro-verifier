# Сообщения об уязвимостях

Не добавляйте секреты в репозиторий. Сообщите об уязвимости приватно через
GitHub Security Advisories этого проекта или по адресу электронной почты
владельца репозитория, указанному в его GitHub-профиле. Не публикуйте
неисправленные уязвимости в открытых issues.

Поддерживается версия из ветки `main`.
